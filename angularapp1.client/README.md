# Frontend Angular

To jest frontend aplikacji systemu kluczykowego.

## Jak uruchomić ten frontend

```bash
npm install
npm start
```

Aplikacja działa pod adresem:
`https://localhost:4200`

## Ważne

- Sam frontend nie wystarczy - backend API też musi działać.
- Jeśli widzisz błąd połączenia, uruchom backend z folderu `AngularApp1.Server`.

## Testy

```bash
ng test
```
